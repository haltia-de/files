# files

«Файлы» и «Галерея» среды [Haltia](https://github.com/haltia-de).
Одна программа с двумя входами: `io.github.haltia_de.Files` и
`io.github.haltia_de.Gallery` — у каждого свой `.desktop`, значок и AppStream
metainfo, так что обе видны в меню любой среды (GNOME, KDE) и в
GNOME Software, а оболочка Haltia ставит их на домашний экран
(`X-Haltia-Home`).

**Файлы** (`haltia-files`): места (Дом, Документы, Загрузки, Изображения,
Музыка, Видео, карта памяти, Система), папки строками или плитками
(«Плитки»/«Список»), фото, видео и обложки музыки — миниатюрами. Касание
открывает файл в нужной программе: текст — Блокнот, фото — тут же (листание
по фото папки), видео — плеер Видео, звук — плеер внизу окна (файлы папки
подряд), PDF — Firefox. Долгое нажатие — редактировать (текст), копировать,
вырезать, переименовать, удалить в корзину.

**Галерея** (`haltia-files --gallery`): все фото, видео и музыка, сохранённые на
планшете (домашняя папка и карты памяти), в одном месте, без папок. Ряд под
шапкой — Все, Фото, Видео, Музыка; кнопка в шапке — вид: Плитки, Список, По
датам (по месяцам), По папкам (альбомы). Фото открываются на весь экран:
‹ › и смахивание — соседние, + − — увеличение, перетаскивание — сдвиг, ▶ —
слайд-шоу. Видео — в плеере Видео, музыка играет в плеере внизу, пока
смотришь дальше. Долгое нажатие — сведения о файле или удаление в корзину
(с вопросом). Найденное в прошлый раз показывается сразу
(`~/.cache/haltia-files/index.json`), новое ищется в фоне.

Увеличение — кнопками: фильтр касаний не пропускает двойное касание. Вид
(шапка, вопросы) даёт тема среды; вопросы — обычные GTK-диалоги из
haltia-kit, настройки — `~/.config/haltia/files.conf` и `gallery.conf`.

До ADR 0004 программа называлась `b8k-files`: старое имя команды и скрытые
`.desktop` старых id остаются до 3.0, настройки и кэш переезжают при первом
запуске.

Нужны Python 3 с PyGObject (GTK 3) и библиотека
[haltia-kit](https://github.com/haltia-de/kit): звук, миниатюры
(стандартные, в `~/.cache/thumbnails`, общие с файловыми менеджерами) и
просмотр фото — из неё. Установка: `sh install.sh [ROOT] [PREFIX]` (по умолчанию `/usr/local`) или
пакет Alpine из `packaging/alpine/APKBUILD`. Проверка
медиатеки: `python3 tests/test_library.py`.
