# b8k-files

«Файлы» для планшета Lenovo YOGA Tablet 10 (B8000-H) с оболочкой
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux).

Файлы крупными строками: места (Дом, Документы, Загрузки, Изображения, Музыка, Видео, карта памяти, Система), папки, открытие файла в нужной программе (текст — Блокнот, картинки — тут же, видео и звук — b8k-vplay, PDF — Firefox), долгое нажатие — копировать, вырезать, переименовать, удалить в корзину.

Нужен только Python 3 с PyGObject (GTK 3); на другом компьютере работает так
же, без вибрации и вопросов в стиле оболочки. Установка: `sh install.sh [ROOT]`.
