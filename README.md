# b8k-files

«Файлы» и «Галерея» для планшета Lenovo YOGA Tablet 10 (B8000-H) с оболочкой
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux).
Одна программа с двумя входами: `io.github.trudenboy.Files` и
`io.github.trudenboy.Gallery` — у каждого свой `.desktop`, значок и AppStream
metainfo, так что обе видны в меню любой среды (GNOME, KDE) и в
GNOME Software, а оболочка планшета ставит их на домашний экран
(`X-B8K-Home`).

**Файлы** (`b8k-files`): места (Дом, Документы, Загрузки, Изображения,
Музыка, Видео, карта памяти, Система), папки крупными строками или плитками
(«Плитки»/«Список»), фото, видео и обложки музыки — миниатюрами. Касание
открывает файл в нужной программе: текст — Блокнот, фото — тут же (листание
по фото папки), видео — b8k-vplay, звук — плеер внизу окна (файлы папки
подряд), PDF — Firefox. Долгое нажатие — редактировать (текст), копировать,
вырезать, переименовать, удалить в корзину.

**Галерея** (`b8k-files --gallery`): все фото, видео и музыка, сохранённые на
планшете (домашняя папка и карты памяти), в одном месте, без папок. Ряд под
шапкой — Все, Фото, Видео, Музыка; кнопка в шапке — вид: Плитки, Список, По
датам (по месяцам), По папкам (альбомы). Фото открываются на весь экран:
‹ › и смахивание — соседние, + − — увеличение, перетаскивание — сдвиг, ▶ —
слайд-шоу. Видео — в b8k-vplay, музыка играет в плеере внизу, пока
смотришь дальше. Долгое нажатие — сведения о файле или удаление в корзину
(с вопросом). Найденное в прошлый раз показывается сразу
(`~/.cache/b8k-files/index.json`), новое ищется в фоне.

Касания одним пальцем: на планшете фильтр касаний пропускает один палец и
не пропускает двойное касание, поэтому увеличение — кнопками. Вид (крупная
шапка, большие вопросы) даёт тема среды; вопросы — обычные GTK-диалоги
из b8k-compat, настройки — `~/.config/b8k/files.conf` и `gallery.conf`.

Нужны Python 3 с PyGObject (GTK 3) и библиотека
[b8k-compat](https://github.com/trudenboy/b8k-compat): звук, миниатюры
(стандартные, в `~/.cache/thumbnails`, общие с файловыми менеджерами) и
просмотр фото — из неё. Установка: `sh install.sh [ROOT] [PREFIX]` (по умолчанию `/usr/local`) или
пакет Alpine из `packaging/alpine/APKBUILD`. Проверка
медиатеки: `python3 tests/test_library.py`.
